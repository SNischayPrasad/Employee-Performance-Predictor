**Caption:**

```
Can data predict who will be a top performer, before the annual review? 📊

I built an end-to-end HR analytics project to find out: Employee Performance Predictor using Data Analytics.

Real HR data is confidential, so I simulated a 2,000-employee company with realistic, messy data (missing values, typos, duplicates) and built the full pipeline:

🔹 Cleaned 350 missing values, outliers & 25 duplicate records
🔹 Engineered features like projects-per-year and overtime hours
🔹 Compared 4 ML models with 5-fold cross-validation
🔹 Predicted Low / Medium / High performers with 76% accuracy on unseen employees
🔹 Turned every prediction into an HR action: promote, train, support or review workload
🔹 Built an interactive Streamlit dashboard for HR teams

💡 Key insights:
• Top drivers: peer feedback, absences, job satisfaction, productivity & training
• Employees with the most training were 3.5× more likely to be top performers
• Working 220+ hours/month lowered performance (burnout is real)

🎯 Biggest lesson: simple Logistic Regression beat Random Forest and Gradient Boosting. More complex isn't always better, and in HR an explainable model wins trust.

⚖️ Built responsibly: no gender or other protected attributes used, and predictions support managers, not replace them.

Tech: Python · Pandas · NumPy · scikit-learn · Matplotlib · Seaborn · Streamlit
```
